Engineering Highlights

Built for True Backtest ↔ Live Parity

Every architectural decision eliminates the silent discrepancies that destroy retail backtests in live production.

🛡️ Zero Look-Ahead by Design

Orders emitted on onBar(bar) fill at the next bar's open with configurable slippage, while past-only indicator history prevents accidental future data leakage.

⚖️ OANDA Hedging & REDUCE_ONLY

Models OANDA hedgingEnabled=true behavior: opposite-side orders can coexist as independent hedges, while .asCloseOnly() guarantees clean position reductions.

⚡ CME Futures Realism

Native point multipliers (MGC $10/oz, MES $5/pt, MNQ $2/pt), tick rounding, session-aware D1/W1 boundaries, and tiered exchange + clearing cost presets.

Developer Experience

Write a Strategy in 30 Lines of Pure Java 21

Implement a single interface in trading-core. Your strategy immediately works in the Desktop Studio, Walk-Forward optimizer, CLI batch runner, and live OANDA / IBKR execution engines.

MyBreakoutStrategy.java — trading-strategies 
package com.martinfou.trading.strategies.custom;

import com.martinfou.trading.core.*;
import java.util.*;

public class MyBreakoutStrategy implements Strategy {
    private final String symbol = "EUR_USD";
    private final List<Bar> history = new ArrayList<>();
    private final List<Order> pending = new ArrayList<>();
    private boolean inTrade = false;

    @Override public String name() { return "MyBreakoutStrategy"; }

    @Override
    public void onBar(Bar bar) {
        if (history.size() >= 20) {
            double high20 = history.subList(history.size() - 20, history.size())
                    .stream().mapToDouble(Bar::high).max().orElseThrow();
            double low10 = history.subList(history.size() - 10, history.size())
                    .stream().mapToDouble(Bar::low).min().orElseThrow();

            if (!inTrade && bar.close() > high20) {
                pending.add(new Order(symbol, Order.Side.BUY, Order.Type.MARKET, 10_000, bar.close())
                        .withStopLoss(low10)
                        .withTakeProfit(bar.close() + 2.0 * (bar.close() - low10)));
                inTrade = true;
            } else if (inTrade && bar.close() < low10) {
                pending.add(new Order(symbol, Order.Side.SELL, Order.Type.MARKET, 10_000, bar.close())
                        .asCloseOnly()); // REDUCE_ONLY parity on OANDA v20
                inTrade = false;
            }
        }
        history.add(bar);
    }

    @Override public void onTick(double bid, double ask, long volume) {}
    @Override public List<Order> getPendingOrders() {
        List<Order> out = new ArrayList<>(pending);
        pending.clear();
        return out;
    }
    @Override public void reset() { history.clear(); pending.clear(); inTrade = false; }
}
Quick Start

Up and Running in 60 Seconds

Requires JDK 21+ (Temurin recommended) and Node.js 20+ for the Desktop Studio.

1. Clone, Build & Launch Desktop Studio 
git clone https://github.com/martinfou/trading-bridge.git
cd trading-bridge

# Build all 11 Maven modules
./mvnw clean install -DskipTests

# Launch Control Plane (:8080) + Electron Desktop App
./start-desktop.sh
2. Run Backtests & Quant CLI (./tb) 
# Interactive Terminal UI (JLine3)
./tb

# Run sample SmaCrossover backtest via Maven
./mvnw exec:java -pl trading-examples \
  -Dexec.mainClass="com.martinfou.trading.examples.RunBacktest" \
  -Dexec.args="--sample"
